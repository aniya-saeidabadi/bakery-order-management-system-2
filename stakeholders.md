# Stakeholders

## 1. Customer

The customer is the person who uses the system to view bakery products and place orders.

Needs:
- View bakery products and prices.
- Place orders.
- Customize cakes.
- Select pickup dates.
- Track order status.

**ترجمه:**

## ۱. مشتری

مشتری فردی است که از سیستم برای مشاهده محصولات قنادی و ثبت سفارش استفاده می‌کند.

نیازها:
- مشاهده محصولات قنادی و قیمت‌ها.
- ثبت سفارش.
- سفارشی‌سازی کیک.
- انتخاب تاریخ دریافت سفارش.
- پیگیری وضعیت سفارش.

## 2. Bakery Staff

Bakery staff are responsible for preparing customer orders.

Needs:
- View customer orders.
- Check order details.
- Update order status.
- View pickup dates.

**ترجمه:**

## ۲. کارکنان قنادی

کارکنان قنادی مسئول آماده‌سازی سفارش‌های مشتریان هستند.

نیازها:
- مشاهده سفارش‌های مشتریان.
- بررسی جزئیات سفارش.
- به‌روزرسانی وضعیت سفارش.
- مشاهده تاریخ‌های دریافت سفارش.

## 3. Bakery Manager

The bakery manager is responsible for managing the bakery's products and orders.

Needs:
- Add new products.
- Update product information and prices.
- View and manage customer orders.
- Monitor order status.

**ترجمه:**

## ۳. مدیر قنادی

مدیر قنادی مسئول مدیریت محصولات و سفارش‌های قنادی است.

نیازها:
- افزودن محصولات جدید.
- به‌روزرسانی اطلاعات و قیمت محصولات.
- مشاهده و مدیریت سفارش‌های مشتریان.
- نظارت بر وضعیت سفارش‌ها.

## 4. System Administrator

The system administrator is responsible for managing system access and user accounts.

Needs:
- Manage user accounts.
- Control access permissions.
- Help maintain system security.

## ۴. مدیر سیستم

مدیر سیستم مسئول مدیریت دسترسی به سیستم و حساب‌های کاربری است.

نیازها:
- مدیریت حساب‌های کاربری.
- کنترل سطوح دسترسی.
- کمک به حفظ امنیت سیستم.
